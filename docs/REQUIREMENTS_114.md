# 114 — Player Inquiry Follow-Up Assessment

## 1. Purpose

114 closes the first complete inquiry loop:

```text
player asks "What happened here?"
→ command lacks supported information
→ information requirement opens
→ subordinate report is acquired
→ requirement becomes SATISFIED
→ command gives the player a follow-up assessment
```

114 is **response/presentation policy only**.

It does not add new collection methods, recon assets, military decisions, player commands, or battlefield UI.

